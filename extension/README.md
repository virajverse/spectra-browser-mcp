# SpectraBrowser MCP — Chrome Extension

Connects your live, logged-in Google Chrome tabs directly to SpectraBrowser MCP without restarts, command-line flags, or security warnings.

## 🚀 How to Install in 30 Seconds:

1. Open your normal **Google Chrome**.
2. In the address bar, paste:
   ```
   chrome://extensions
   ```
3. In the top-right corner, turn **ON** the switch: **Developer mode**.
4. In the top-left corner, click **Load unpacked**.
5. Select this folder:
   ```
   c:\Users\FEARLESS\Downloads\testing agent\spectra-browser-mcp\extension
   ```
6. Done! 🎉 You will see **SpectraBrowser MCP Bridge** in your extensions list.

---

## 🎯 How to Use:
1. Click the puzzle icon 🧩 in Chrome's top right toolbar and pin **SpectraBrowser**.
2. Click the **SpectraBrowser** extension icon on any tab.
3. Click **Attach MCP to Tab**.
4. Now your AI / MCP tools can navigate, click, inspect elements (`@ref`), and take screenshots directly inside your personal logged-in Chrome!
